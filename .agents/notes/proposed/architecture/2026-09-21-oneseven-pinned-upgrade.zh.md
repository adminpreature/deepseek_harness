# Agent Note: OneSeven upgrade on a pinned official release

Status: proposed

[English](2026-09-21-oneseven-pinned-upgrade.md) | 中文

## Problem

壹柒需要以完整官方 `dsh-v0.1.6-alpha.2` 应用为基础，重新适配品牌、四个外部插件和 Docker 部署。复制旧前端或在旧底座拼装官方功能会丢失新版 Session、侧栏和插件生命周期行为。

## Proposal

将官方标签作为固定源码基线，自有定制分成独立、可审查的改动迁移。原工作目录、未提交技能工作区、凭据和运行数据不混入升级分支。用户已确认视觉方案，要求完整支持亮色和暗色主题；未经另行授权不提交、推送、合并或部署。

### 部署与数据

本机观察到 `~/.dsh/sessions/**/session.jsonl.zstd`、工作区/投影 JSON 存储、插件 JSON/文件、Profile、设置及凭据文件。凭据与内容未输出或放入分支。此为本机证据，不能证明生产卷后端。目标 `SESSION_FORMAT_VERSION` 为 3；迁移测试只能读取历史会话副本。

Docker 需包含目标原生构建与锁文件、源码构建技能广场、精确外部插件版本，以及保留用户 patch 和禁用标记的幂等 Profile 更新。旧入口仅在 package.json 不存在时初始化，不更新已有卷。旧 Dockerfile 依赖被忽略的 plaza lib/node_modules，并以 `|| true` 包裹检查，不沿用这些掩盖失败的假设。

容器内回环监听不能通过普通 bridge 端口发布访问；需实测所选代理/网络路径，不能相信旧注释。目标 webserver 支持显式非回环监听，但不自带全局认证。宿主端口绑定回环，保留目标 token/trust 控制并配置带认证的 TLS 代理，不默认扩大权限或可信主机。

迁移前识别实际实例、镜像摘要、卷挂载与后端，停止写入，私有备份旧镜像、配置、插件文件和完整升级前数据。新实例使用独立副本。回滚先停止新写入者，再同时恢复旧代码/镜像/配置与升级前数据卷，并运行读写冒烟。即使旧会话代际仍存在，也不能将旧二进制直接指向新卷降级。生产实例身份与回滚演练尚未验证。

## Alternatives considered

**合并当前开发 master：** 拒绝，固定发行版才是验收基线。**合并无关历史：** 拒绝，没有共同祖先且已精确识别初始导入树。**复制旧前端：** 拒绝，Session factory、Lexical、右侧多标签及插件生命周期均有变化。**展示模式优先：** 不推荐用于本次任务导向 No Hero 工作台；需明确批准及单独的依赖/性能决策。

### 品牌实现检查点

私有 `ui-brand-oneseven` 插件集中维护双色 Tokens、本地化品牌插槽及可撤销的 DOM 样式与元数据。上游主题注册表、基础组件、停靠面板与 agent-loop 保持原位。`ui-theme` 接受经过验证的部署默认值；OneSeven 组合仅在偏好未设置时默认暗色，保留已保存选择。默认根构建向外壳和动态插件传入一致的 OneSeven 标题与构建标记。新品牌包明确排除在官方 npm 发布成员之外并设为私有，相邻官方包的发布检查不变。这是本地构建发行版，不授权执行上游发布流程。

新任务标题改为任务型文案。静态资源沿用原 Logo。字体改为本机普惠体字形与系统字体回退，不下载字体二进制文件，避免在未核实授权的情况下分发变换字体。品牌调色板及字典、插槽注册随插件 fiber 卸载。公共 README/JSDoc、生成的配置与插槽目录以及 keyless 界面期望均随实现更新。

已在定制构建中验证：123 项主题/对话/构建环境聚焦单测、21 项包发布策略测试、完整构建、16 项 hygiene 检查及定向 lint。浏览器回放覆盖深浅主题、设置与页面刷新、390px 布局、文件/Office 预览及预览双色、Diff、终端进程和调色板、归档恢复、待发送队列编辑、上传、发送/取消/错误/重试、内置插件管理和子代理对话。这些是 keyless 夹具及本地进程验证，不是真实模型或生产验证。终端期望明确更新为批准的调色板，程序自定义 ANSI 颜色及光标可读性断言保留。实际应用截图与此前静态设计稿分开保存。

首轮浏览器失败暴露了旧浅色默认值及上游精确颜色的测试假设，已通过明确测试前置主题和审查后的配色期望处理。新增浏览器测试的编译面登记错误曾在无关源码旁生成 56 个构建文件；修正 host/client 项目归属后，已将这些生成文件隔离到私有证据目录，未移除原工作区文件。

仍待完成：Docker 镜像及入口脚本、新旧卷 Profile 初始化、历史数据副本迁移与回滚演练，以及其余验收状态。生产配置、数据卷、实验驱动默认值均未变更，未提交或推送。本检查点不代表整个任务完成。

质量审计发现 seeded-history 仍断言旧配色，以及首屏下载三份全量字体。上下文说明用例现分别校验已批准的亮暗配色，并在 finally 中恢复设置和展开状态；后继 ARIA 期望保持不变。全新中英文浏览器上下文断言零字体请求。修正后的完整构建与四文件浏览器回放通过（27 项，另有一项仅录制时运行而跳过）；此前通过的检查并未覆盖这两个遗漏。

### 外部插件实现检查点

四个插件维护在私有 `external-plugins` 源码目录中，通过独立 managed-profile 测试加载，不复制旧前端目录或改写真实 Profile。广场和看板使用官方面板插槽；广场等待对话持久化监听重挂载后定向交付技能。看板权限设置失败时不提交任务；技能管理适配严格 codec 工厂与设置命名空间；提示词管理保留会话隔离和跨域／远程写入拒绝。窄屏设置导航换行到完整宽度内容上方，不移除分区或关闭操作。

两个旧插件仅取得可维护的发布 JavaScript，未伪造声明文件或补齐缺失许可证。没有复制旧运行时；精确 peer 版本映射到固定检出目录。兼容测试经过真实 Web 加载、持久存储、刷新、卸载重载和本地 Agent 执行；本地确定性适配器不代表真实模型验证。源码方式、逐项验证与限制统一维护在[外部插件说明](../../../../external-plugins/README.zh.md)。原技能工作区、用户数据及实验驱动默认值未改动。

## Risks

旧插件可能修改错误输入器或卸载后泄漏监听；运行时 peer 可能产生重复服务实例；已有卷初始化若简单重写会丢失配置；原生依赖与容器网络需独立测试；已迁移数据不能替代升级前回滚副本。目标实验浏览器/电脑驱动保持可选启用，未授权生产部署。
