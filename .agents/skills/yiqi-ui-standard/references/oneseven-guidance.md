# OneSeven 品牌与设计指导

本文件用于壹柒研究所及其产品的 UI 生成和审查。目标是在默认暗色、排版角色范围和卡片连续大圆角等共享硬边界内，按产品任务校准布局、控件尺寸和信息密度。

## 适用范围

出现以下任一信号时启用本指导：

- 用户明确提到 `OneSeven`、`壹柒研究所` 或 `17 RESEARCH INSTITUTE`
- 项目标题、Logo、仓库名称或页面文案明确属于壹柒研究所
- 用户明确要求按 OneSeven 品牌标准生成或审查

正式范围包括官网、AI 对话、AI 绘画、智能体、钱包、个人中心和管理后台。

不包括：

- 当前隐藏的案例页面
- 外部 AI 画布的内部界面
- 圆桌会议 iframe 内部界面

对外部产品只检查主站入口、承载容器和品牌衔接。

## 规则优先级

审查 OneSeven 产品时按以下顺序判断：

1. 本文件中的品牌原则
2. 当前产品已经形成的局部设计系统
3. 通用可用性、可访问性和交互质量
4. `visual-system.md` 等通用参考

本文件与通用示例冲突时，以本文件的共享硬边界为准。间距、断点和控件尺寸按产品校准；默认暗色、标题角色、Hero 和卡片规则不得作为普通产品差异跳过。

## 品牌硬规则

### Logo

- 唯一正式标志为 `../assets/oneseven-logo.png` 中的图形 Logo
- 浅色背景使用黑色 Logo，暗色背景使用白色反相 Logo
- 保持原始比例、轮廓完整和足够留白
- 禁止拉伸、旋转、描边、渐变填充、发光或添加无意义阴影
- Logo 默认不使用紫色填充
- 尺寸和安全距离以清晰、不拥挤为准，不强制固定比例

### 颜色

- 品牌紫基准色为 `#9A6ABA`
- 紫色用于点缀、焦点、选中状态、关键操作和少量品牌强调
- 紫色不是必须覆盖大面积背景的主导色
- 不同产品可以建立自己的中性色、语义色和紫色衍生色
- 同一产品内的颜色角色必须稳定：相同颜色应表达相同含义
- 明暗主题应保持信息层级和语义关系，不要只做机械反色

### 字体

- 品牌字体为 `Alibaba PuHuiTi`
- 轻盈的 `200` 字重是主要品牌特征
- 官方 WOFF2 文件位于 `../assets/fonts/`，`theme.css` 已配置 `200 / 400 / 500 / 600`
- 生成 Web 代码时优先复用包内字体文件，不依赖用户系统是否已安装字体
- 产品可以为了可读性、数据识别或关键状态使用其他已有字重
- 不因局部使用不同字重直接判定违规，重点检查层级是否清楚、字体是否真实加载
- 回退字体应包含适合中文环境的系统字体

## 相对统一原则

### 品牌气质一致

不同产品应让用户感到属于同一品牌，但不要求看起来像同一个页面模板。

保持关联的信号包括：

- 同一 Logo 和品牌名称
- Alibaba PuHuiTi 的排版气质
- 克制使用的品牌紫
- 清晰、安静、重视内容和任务的界面表达
- 及时、可信、可理解的交互反馈

### 产品内部一致

优先检查一个产品内部是否形成稳定规则：

- 相同外观的元素是否具有相同作用
- 同类组件是否使用一致的状态和交互方式
- 颜色、圆角、间距和阴影是否存在可识别的局部规律
- 新增样式是否延续已有规律，还是无理由增加新的变体

允许官网、创作工具和后台拥有明显不同的密度与布局。

### 共享范围与产品校准

- 默认暗色；只有用户明确请求时生成浅色主题
- Marketing H1：桌面 36–42px，移动 30–36px
- Page Title：桌面 28–32px，移动 24–28px
- Section Title：桌面 22–24px，移动 20–22px
- Card Title：桌面 16–20px，移动 16–18px
- SaaS Page Title：20–24px；SaaS Panel Title：16–18px；SaaS Body / Controls：13–16px
- 所有独立卡片桌面使用 36px 连续大圆角；移动端使用 28–36px、默认 32px，并保持 squircle；不得低于 28px，不得另建小圆角系统
- 生成前必须询问使用实体材质还是液态玻璃；玻璃仅在用户选择后启用
- 玻璃材质不得嵌套；减少透明或不支持 backdrop filter 时必须降级为实体背景、实体边框和 solid shadow，并关闭 backdrop
- 减少透明与不支持 backdrop filter 两个降级场景复用 solid token，不复制另一套值
- 在上述范围内按产品主类型、页面任务、容器尺度和信息密度选值；布局、控件尺寸与局部密度继续产品化校准

以下情况应判定为问题：

- 标题超出角色范围、同一视口重复 H1，或字号随视口无限放大
- 卡片退回控件级小圆角、同页混用材质，或把每个结构区域包装成卡片
- 未询问就启用液态玻璃，玻璃背景损害对比度，或缺少减少透明降级
- 同类控件出现无理由差异，造成对齐、响应式、可用性或维护问题

## Apple Design 参考

如环境中存在 `apple-design` Skill，可将其作为设计判断参考。Apple Design 不是默认视觉模板，也不是强制检查表。

重点参考：

- **Purpose**：每个元素服务于明确目的
- **Agency**：用户保持控制，错误操作可以恢复
- **Familiarity**：遵循用户熟悉的交互方式
- **Simplicity**：突出主要任务，而不是追求表面极简
- **Feedback**：操作及时得到状态、完成、警告或错误反馈
- **Spatial consistency**：进入、退出和触发位置保持空间联系
- **Flexibility**：适应不同设备、产品形态和用户能力
- **Craft**：重视排版、对齐、响应、动效和细节质量

不要据此自动推导：

- Apple 风格的视觉外观
- 玻璃材质或毛玻璃；glass 仅在用户选择后使用
- 弹簧动画
- Apple 特有的圆角、尺寸或排版
- 特定导航和组件结构

桌面 36px；移动 28–36px、默认 32px；同一连续卡片语言。该规则是本 Skill 已批准的共享规则，不是从 Apple Design 自动推导出的外观，也不能继续推导其他 Apple 视觉特征。实体材质与液态玻璃都必须遵守这一语言。

动效应优先满足及时、连续、可理解和可中断；实现方式由产品和技术条件决定。

## 产品差异示例

### 官网

允许宽松留白、沉浸式内容、品牌叙事和更强的视觉表达。重点检查品牌识别、内容层级、阅读节奏和主要入口。

### AI 工具

允许紧凑布局、固定侧栏、密集工具栏和持续操作界面。重点检查工作流效率、状态反馈、可恢复性和输入输出关系。

### 管理后台

允许高信息密度、较小控件和克制的品牌表达。重点检查扫描效率、筛选比较、批量操作、权限风险和数据可读性。

不得因为三类产品的布局、控件尺寸或局部密度不同而要求它们互相复制。桌面 36px；移动 28–36px、默认 32px；同一连续卡片语言。独立卡片仍遵守共享材质规则。

## 审查输出

OneSeven 审查报告使用以下结构：

```markdown
## OneSeven UI 审查

### 共享硬边界问题
列出 Logo、品牌字体、品牌紫、默认暗色、排版角色、Hero 和卡片规则的明确冲突，并标记为必须修复。

### 产品内部一致性
列出同类元素行为不一致、无理由变体、局部系统失控等问题。

### 体验与可用性建议
列出任务层级、反馈、导航、响应式、可访问性等建议。

### Apple Design 参考
仅提供适用的设计判断，不作为强制整改项。

### 做得好的地方
说明当前产品已经形成的有效设计规律。
```

默认暗色、排版角色、Hero、卡片等共享硬边界冲突必须作为强制问题。只有布局、控件尺寸、局部密度等合理产品差异使用“建议”措辞。
