# 产品画像与复合型校准

产品画像用于决定整体设计方向，页面画像用于按当前任务校准布局。不得把复合产品强行归入单一类型。

## 两层画像

### 产品级画像

每个产品确认 **1 个主类型** 和 **0–3 个次类型**。

- 主类型决定整体导航、默认信息密度、核心工作节奏和主要壳层。
- 次类型只补充其对应功能，不得取代主类型或把整套产品改造成另一种原型。
- 品牌、暗色主题、字体范围、连续圆角和卡片材质保持产品级关联，在不同页面之间延续一致的产品身份。

### 页面级画像

每个页面或路由按当前主要任务重新分类，页面级画像可以覆盖产品级默认布局和密度。逐页判断：

- 主要任务：浏览、创建、管理、分析、交易、协作。
- 信息密度：低、中、高。
- 使用节奏：一次性、周期性、持续工作。
- 操作风险：普通、敏感、不可逆。
- Hero / No Hero。
- approved layout（已批准布局方向）：从当前页面对应的 Hero、SaaS 或其他产品规范中选择并经用户批准的结构方向，不是固定全局模板。

## 十二类产品原型

1. **品牌官网 / 营销转化**：突出品牌认知、价值表达、信任建立和转化路径。
2. **产品介绍 / 发布页面**：围绕单一产品、版本或活动组织叙事、演示和发布行动。
3. **内容 / 知识 / 文档**：优先保证阅读、检索、目录定位、引用和知识连续性。
4. **电商 / 交易 / 支付**：围绕商品发现、比较、下单、支付、订单状态和交易信任设计。
5. **社区 / 协作 / 消息**：支持内容流、成员关系、讨论、通知和多人协同反馈。
6. **C 端工具 / 移动应用**：聚焦个人高频任务、快速反馈、轻量导航和触屏操作。
7. **运营管理 SaaS**：强调高密度管理、批量操作、状态追踪、权限和持续工作效率。
8. **AI 创作 / 对话工作台**：围绕提示、上下文、生成、编辑、版本和结果复用组织工作区。
9. **数据分析 / 监控看板**：优先保障指标辨识、趋势比较、异常发现、筛选和下钻分析。
10. **平台 / 市场 / 多角色系统**：处理多角色入口、供需匹配、权限边界、资源流转和平台规则。
11. **个人中心 / 钱包 / 账户**：组织身份、资产、账单、安全、偏好和账户状态。
12. **表单流程 / 向导 / 申请系统**：强调步骤进度、输入校验、材料提交、保存恢复和结果确认。

## 冲突处理

当产品级与页面级规则、品牌表达或视觉偏好冲突时，严格按以下顺序处理，前项优先于后项：

1. 安全、可用性和任务效率
2. 当前页面的主要任务
3. 当前页面类型
4. 产品主类型
5. 产品次类型
6. 品牌视觉表达

品牌信号继续保留，但不能破坏高密度工作流、数据辨识和关键操作。

## 复合产品示例

一个 AI 商业平台可以采用以下画像：

- 主类型：AI 创作 / 对话工作台。
- 次类型：运营管理 SaaS、数据分析 / 监控看板、电商 / 交易 / 支付。
- 官网：品牌官网 / 营销转化，有 Hero。
- 创作区：AI 创作 / 对话工作台，无 Hero。
- 项目管理：运营管理 SaaS。
- 数据中心：数据分析 / 监控看板。
- 订阅结算：电商 / 交易 / 支付，并按敏感或不可逆操作处理交易与风险。
