# UI 审查检查清单

## 审查入口

先记录：

1. 品牌模式
2. 产品主类型和 0–3 个次类型
3. 当前页面类型和主要任务
4. 信息密度、使用节奏和风险等级
5. Hero / No Hero
6. 卡片材质
7. 平台和技术栈

不得先拿通用数值表逐项比对。

## 阻塞问题

- 品牌 Logo、字体或品牌紫角色明确冲突
- 默认生成结果不是暗色
- 品牌/产品页 H1 超过 42px，或移动端超过 36px
- SaaS 页面标题超过 24px
- SaaS、AI 持续操作、管理、分析、账户页面错误使用营销 Hero
- Hero 使用默认左右文案/装饰图分栏
- Hero 使用大型抽象圆形、光球或无信息几何体代替真实视觉
- Hero 缺少品牌/产品第一信号、真实视觉证据或下一内容提示
- 卡片未确认材质，未使用连续大圆角，或出现无必要卡片嵌套
- 液态玻璃缺少对比度、背景内容或减少透明降级
- 交互缺少焦点、等待、完成、错误或恢复状态
- 未执行静态校验，或没有桌面和移动截图
- 静态校验存在 error，或静态 warning 未在浏览器复核并记录

静态 error 阻塞完成。静态 warning 本身不等于错误，但必须在浏览器中复核并记录；未完成复核和记录时，验收流程仍未完成。

## 产品内部一致性

- 同类元素是否具有相同作用、状态和交互
- 颜色、间距、控件高度和阴影是否形成可识别的局部规律
- 是否出现无理由的新变体
- 高密度工作台是否因大圆角或装饰卡片损失空间效率
- 固定格式控件、表格、画布和指标区域是否保持稳定尺寸

## 体验与可用性

- 主要任务、数据和状态是否进入第一视口
- 横向溢出、文字遮挡、截断和按钮文字溢出
- 键盘焦点、点击区域和对比度
- 危险操作确认、可撤销或恢复路径
- `prefers-reduced-motion` 和减少透明支持
- 字体文件是否真实加载并使用正确字重

## 输出格式

```markdown
## OneSeven UI 审查

### 品牌基础问题
| 位置 | 当前状态 | 应该改成 | 原因 |

### 产品内部一致性
| 位置 | 当前状态 | 建议改成 | 原因 |

### 体验与可用性建议
| 位置 | 当前状态 | 建议改成 | 原因 |

### Apple Design 参考
只列适用的设计判断，不把 Apple 外观当作强制模板。

### 做得好的地方
说明已经形成的有效规律。
```

首次审查最多输出 Top 5 阻塞问题和 Top 3 推荐改进。每项必须包含文件或页面位置、当前状态、修复方向和规则依据。
