# dsh-skill-plaza

[English](README.md) | 中文

技能目录使用官方主面板、侧栏与输入插槽。输入框下方的 **Skill** 按钮打开可搜索的选择器；选择技能会在当前草稿前插入 `/slug `，不自动发送。按 Escape、点击关闭或弹层外部可退出选择器，不改变草稿。完整技能广场在面板重新挂载后保留所选会话的草稿。

## 随包技能

插件在 `skills/` 中附带 80 个内容型技能：法律（12）、科学研究与生命科学（18）、企业办公（15）、创业营销电商运营（25）、决策顾问（10）。每份原始 `SKILL.md` 保持不变：`metadata.slug` 用作调用标识，`name` 用作中文展示名，上级分类用于广场筛选。两个入口均支持搜索名称和描述；选择器还支持搜索分类和调用标识。无论界面语言如何，技能正文均为中文。

可逆的 `oneseven-presets` provider 以随包优先级向 `ctx.skills` 注册资源。已有的更高优先级技能可以覆盖同名标识。资源缺失、元数据无效、正文为空或标识重复均会导致插件启用失败。资源随插件打包，不依赖开发机器路径。禁用插件会移除其 provider 和两个界面入口，已有会话记录保持不变。

## 模型体验

注册表向现有模型技能目录提供技能描述。显式 `/slug` 调用复用现有宿主技能加载器，注入的指令会记录到会话中。仅选择技能不会调用模型。这些技能用于分析所提供的材料和起草内容，不授予外部账号访问权、执行权限或专业资质。每份正文中的原有安全限制与人工复核要求均予保留。

## 已知限制与后续工作

选择器和广场浏览默认预设的技能目录，不展示自定义会话预设独有的工作区技能。选择技能不会安装工具或提交任务。修改本检出目录以外的原始文件夹不会自动更新随包资源；重新构建前需复制并校验修订后的资源。用户提供内容的公开分发权利需要另行确认。

构建步骤、来源记录、兼容验证与限制见[外部插件说明](../README.zh.md)。本包为私有下游适配，不改变原已安装 Profile，也不授权公开发布。
