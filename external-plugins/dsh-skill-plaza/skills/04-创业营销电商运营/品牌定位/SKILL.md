# 品牌定位

## 目标

将客户认知、竞争环境和品牌能力整理成清晰、可信且可执行的定位。

## 使用边界

- 这是内容分析与决策辅助技能，不自动访问外部账号、平台、数据库或私有系统，也不代替用户执行发布、发送、购买或其他操作。
- 不把缺失信息补成事实；信息不足时先列出关键缺口，并在合理假设下给出标注清楚的暂定方案。
- 明确区分用户提供的事实、分析推断与行动建议；数字结论注明口径、时间范围和不确定性。
- 不承诺增长、销量、融资、排名或其他商业结果；建议应包含验证方式和停止条件。

## 需要的输入

- 品牌或产品信息
- 目标客户
- 竞争环境
- 客户证据与品牌约束

缺少非关键输入时可以继续，但必须声明假设；缺少会改变结论的核心信息时，先提出少量、具体的问题。

## 工作流程

1. 明确服务对象和关键场景。
2. 提炼客户最在意的结果与阻碍。
3. 寻找品牌可证明的差异。
4. 形成定位陈述、价值支柱和不应使用的表达。
5. 检查定位是否具体、可信和可持续。


## 输出要求

- 定位陈述
- 目标受众
- 价值支柱与证据
- 品牌边界
- 验证建议


输出先给结论和优先级，再给依据。每项建议尽量包含负责人或适用对象、下一动作、衡量信号和复盘时间；不要只罗列通用口号。

## 质量检查

- 是否围绕用户的具体目标、受众和约束，而不是套用模板。
- 是否保留反证、替代解释和未知信息。
- 是否把观察到的相关性误写成因果关系。
- 是否给出了可以验证、排序和停止的下一步行动。
- 是否避免虚构客户反馈、市场数据、竞品能力、引用或来源。
