# 统计分析方案

## 目标

形成可审查、可复现的统计分析计划。默认提供方法选择、变量定义和代码草稿，不声称已经运行分析或得到结果。

## 工作流程

1. 定义研究问题、分析人群、分析单位、主要与次要结局及估计目标。
2. 梳理变量类型、层级结构、重复测量、聚类、删失和时间依赖性。
3. 规划描述性统计和可视化，避免只报告均值或 P 值。
4. 选择与结局分布和研究设计匹配的模型，并写明关键假设。
5. 说明协变量选择依据，避免仅按单变量显著性筛选。
6. 规划缺失数据机制评估、异常值处理和数据变换。
7. 处理多重比较、亚组、交互、模型诊断和敏感性分析。
8. 指定报告效应量、置信区间、绝对风险或实际意义的方式。
9. 如需代码，生成带注释的代码草稿，并列出数据字段和运行环境要求。

## 输出格式

- **分析目标与假设**。
- **数据结构和变量字典**。
- **分析人群与排除规则**。
- **描述性分析计划**。
- **主要、次要和探索性模型**。
- **缺失值、多重比较和敏感性分析**。
- **模型诊断与报告标准**。
- **代码草稿与未执行声明**（如需要）。

## 质量检查

- 方法由问题和数据结构决定，不按软件菜单选择。
- 不把 P 值当作效应大小或证据概率。
- 不在看过结果后把探索性分析伪装成预设分析。
- 未拿到数据时不生成虚假数值、图表或检验结果。

## 能力边界

- 这是研究、规划、整理型内容技能，不把建议、推演或代码草稿描述为已经完成的检索、实验或计算。
- 只有在当前环境确实提供并成功调用相应工具，或用户提供了可核验结果时，才能声称查询过数据库、运行过代码或分析过数据；否则必须明确标注“未实际执行”。
- 不虚构 PubMed、UniProt、PDB 或其他数据库的检索结果、文献、DOI、 accession、实验数据和统计结果。
- 不声称已经运行 Python/R、RNA-seq、单细胞分析、分子动力学、药物筛选或大型基因组分析；可以给出分析计划、伪代码或代码草稿，并明确需要用户在合适环境中验证。
- 区分用户提供的事实、外部证据、合理推论和待验证假设；信息不足时列出缺口，不用臆测补齐。
- 如任务涉及医学或个体健康，不诊断、不开药、不提供或调整剂量、不建议停药、不替代医生，也不根据单一报告断言患病或治疗结论。
