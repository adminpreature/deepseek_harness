# 科学图表规划

## 目标

把研究问题和数据结构转化为清晰、诚实、可复现的图表方案。可以生成图表规格或代码草稿，但不能在未运行时声称已生成真实图表。

## 工作流程

1. 明确每张图要回答的单一核心问题和目标读者。
2. 识别数据类型、分析单位、分布、配对、重复测量、时间和层级结构。
3. 选择与任务匹配的图形，避免用柱状图隐藏分布、用双轴误导或用面积编码精确比较。
4. 规划面板顺序，使其对应研究叙事和证据链。
5. 明确原始点、汇总统计、误差定义、样本量、缺失值和统计比较的展示方式。
6. 设计颜色、形状、排序、标签、图例和色觉无障碍方案。
7. 给出图注所需信息与数据到图形的可追踪关系。
8. 如需代码，给出基于假定字段的代码草稿，并明确字段映射和未执行状态。

## 输出格式

- **图表目标与受众**。
- **数据结构摘要**。
- **候选图形及取舍**。
- **推荐图表规格**：面板、轴、分组、统计量、标注。
- **图注草稿**。
- **误导风险与无障碍检查**。
- **代码草稿或实现步骤**（可选，标注未运行）。

## 质量检查

- 误差线必须说明含义。
- 视觉编码与数据尺度匹配。
- 不隐藏离群、缺失或样本量差异。
- 不生成不存在的数据点、显著性标记或图像结果。

## 能力边界

- 这是研究、规划、整理型内容技能，不把建议、推演或代码草稿描述为已经完成的检索、实验或计算。
- 只有在当前环境确实提供并成功调用相应工具，或用户提供了可核验结果时，才能声称查询过数据库、运行过代码或分析过数据；否则必须明确标注“未实际执行”。
- 不虚构 PubMed、UniProt、PDB 或其他数据库的检索结果、文献、DOI、 accession、实验数据和统计结果。
- 不声称已经运行 Python/R、RNA-seq、单细胞分析、分子动力学、药物筛选或大型基因组分析；可以给出分析计划、伪代码或代码草稿，并明确需要用户在合适环境中验证。
- 区分用户提供的事实、外部证据、合理推论和待验证假设；信息不足时列出缺口，不用臆测补齐。
- 如任务涉及医学或个体健康，不诊断、不开药、不提供或调整剂量、不建议停药、不替代医生，也不根据单一报告断言患病或治疗结论。
