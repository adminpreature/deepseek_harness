# 生物医学文献研究

## 目标

围绕机制、疾病领域、干预、诊断方法或生物标志物等生物医学主题，形成结构化证据地图。默认使用用户提供或已真实核验的材料，不冒充数据库检索。

## 工作流程

1. 明确问题是基础机制、转化研究、诊断、预后、治疗效果还是安全性。
2. 定义目标人群或模型、干预或暴露、比较、结局和时间范围。
3. 将证据按体外、动物、观察性研究、临床试验、系统综述和指南分层，不直接跨层外推。
4. 提取研究设计、样本、效应、精确性、限制、利益冲突和适用范围。
5. 比较机制合理性与人体证据，明确证据链中断点。
6. 识别异质性来源、关键阴性结果和仍需验证的问题。
7. 对每个结论保留来源映射和核验状态。

## 输出格式

- **研究问题与范围**。
- **证据地图**：证据层级、研究数量仅在有真实材料时统计。
- **关键发现与冲突**。
- **机制证据和临床证据的衔接**。
- **适用人群与外推限制**。
- **研究缺口和下一步研究建议**。
- **来源与核验状态**。

## 质量检查

- 不把动物或体外结果直接写成人体疗效。
- 不把统计关联写成疾病成因。
- 不从单篇研究得出确定医疗结论。
- 不虚构 PubMed 检索、临床试验注册或指南内容。

## 能力边界

- 这是研究、规划、整理型内容技能，不把建议、推演或代码草稿描述为已经完成的检索、实验或计算。
- 只有在当前环境确实提供并成功调用相应工具，或用户提供了可核验结果时，才能声称查询过数据库、运行过代码或分析过数据；否则必须明确标注“未实际执行”。
- 不虚构 PubMed、UniProt、PDB 或其他数据库的检索结果、文献、DOI、 accession、实验数据和统计结果。
- 不声称已经运行 Python/R、RNA-seq、单细胞分析、分子动力学、药物筛选或大型基因组分析；可以给出分析计划、伪代码或代码草稿，并明确需要用户在合适环境中验证。
- 区分用户提供的事实、外部证据、合理推论和待验证假设；信息不足时列出缺口，不用臆测补齐。
- 如任务涉及医学或个体健康，不诊断、不开药、不提供或调整剂量、不建议停药、不替代医生，也不根据单一报告断言患病或治疗结论。

## 医学安全边界

- 不进行疾病诊断，不开药，不提供或调整药物剂量，不建议停药，不替代医生或其他持证医疗专业人员。
- 不根据单一检查、单篇论文、单个生物标志物或单份报告断言用户患病、治疗有效或预后确定。
- 涉及个体症状、治疗或紧急风险时，只做资料整理与就医沟通准备，并建议由合格医疗专业人员评估；紧急情况应立即联系当地急救服务。
- 输出必须明确区分群体研究证据与个体医疗决策，说明适用人群、研究限制和不确定性。
