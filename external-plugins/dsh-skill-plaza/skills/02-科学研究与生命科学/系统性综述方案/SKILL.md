# 系统性综述方案

## 目标

生成可供团队讨论、预注册或伦理与方法学审查的系统性综述方案。输出是方案，不代表检索、筛选、质量评价或荟萃分析已经执行。

## 工作流程

1. 明确综述类型、研究问题、目标人群或系统、干预或暴露、比较和结局。
2. 写出纳入与排除标准，包括设计、时间、语言、出版状态和场景。
3. 设计数据库与灰色文献检索、更新检索、引文追踪和检索记录方式。
4. 规定去重、双人筛选、分歧解决和排除原因记录流程。
5. 定义数据提取字段、重复提取或核验方式及缺失数据处理。
6. 选择与研究设计匹配的偏倚风险工具，并说明判断如何进入合成。
7. 预先规定定性合成或定量合成条件、效应量、异质性、亚组、敏感性和发表偏倚分析。
8. 设计证据确定性评估、方案偏离记录和版本管理。

## 输出格式

1. 标题与研究背景。
2. 目标和结构化研究问题。
3. 资格标准。
4. 信息来源与检索策略草稿。
5. 研究记录管理与筛选流程。
6. 数据提取表字段。
7. 偏倚风险评估计划。
8. 数据合成与异质性计划。
9. 证据确定性与报告规范。
10. 伦理、利益冲突、时间表和方案修订记录。

## 质量检查

- 方法在看到结果前尽量预先规定，减少结果导向调整。
- 不默认所有研究都能合并做荟萃分析。
- 工具与研究设计匹配，不机械套用清单。
- 明确这是方案草稿，不生成虚假注册号或执行结果。

## 能力边界

- 这是研究、规划、整理型内容技能，不把建议、推演或代码草稿描述为已经完成的检索、实验或计算。
- 只有在当前环境确实提供并成功调用相应工具，或用户提供了可核验结果时，才能声称查询过数据库、运行过代码或分析过数据；否则必须明确标注“未实际执行”。
- 不虚构 PubMed、UniProt、PDB 或其他数据库的检索结果、文献、DOI、 accession、实验数据和统计结果。
- 不声称已经运行 Python/R、RNA-seq、单细胞分析、分子动力学、药物筛选或大型基因组分析；可以给出分析计划、伪代码或代码草稿，并明确需要用户在合适环境中验证。
- 区分用户提供的事实、外部证据、合理推论和待验证假设；信息不足时列出缺口，不用臆测补齐。
- 如任务涉及医学或个体健康，不诊断、不开药、不提供或调整剂量、不建议停药、不替代医生，也不根据单一报告断言患病或治疗结论。
