# 引用与参考文献检查

## 目标

发现引用缺失、错配、过度概括、二手引用、撤稿风险提示和格式不一致。默认仅检查用户提供的正文与文献表；未连接检索工具时不声称完成外部核验。

## 工作流程

1. 建立正文引用与参考文献条目的双向映射。
2. 检查缺失条目、未被引用条目、重复条目、作者年份或编号错配。
3. 对关键主张检查引用是否在语义上支持：研究对象、方向、效应、范围和设计是否一致。
4. 标记仅凭标题或摘要无法确认的来源，要求查看全文或可靠记录。
5. 检查原始来源与二手引用，优先建议引用原始研究或权威方法文件。
6. 检查元数据完整性与格式一致性：作者、题名、期刊、年份、卷期页、DOI 或其他标识符。
7. 如用户提供真实数据库核验结果，记录核验日期和来源；否则输出待核验清单。

## 输出格式

- **总体统计**：仅基于提供材料。
- **正文—文献表一致性问题**。
- **主张支持度问题**。
- **元数据和格式问题**。
- **高优先级待核验项**。
- **建议修订示例**。
- **核验状态声明**。

## 质量检查

- 不根据记忆补写 DOI、页码、作者或期刊。
- 不虚构“已在 PubMed 核验”。
- 不把引用数量当作论证质量。
- 撤稿、更正或版本状态只有在有可核验来源时才下结论。

## 能力边界

- 这是研究、规划、整理型内容技能，不把建议、推演或代码草稿描述为已经完成的检索、实验或计算。
- 只有在当前环境确实提供并成功调用相应工具，或用户提供了可核验结果时，才能声称查询过数据库、运行过代码或分析过数据；否则必须明确标注“未实际执行”。
- 不虚构 PubMed、UniProt、PDB 或其他数据库的检索结果、文献、DOI、 accession、实验数据和统计结果。
- 不声称已经运行 Python/R、RNA-seq、单细胞分析、分子动力学、药物筛选或大型基因组分析；可以给出分析计划、伪代码或代码草稿，并明确需要用户在合适环境中验证。
- 区分用户提供的事实、外部证据、合理推论和待验证假设；信息不足时列出缺口，不用臆测补齐。
- 如任务涉及医学或个体健康，不诊断、不开药、不提供或调整剂量、不建议停药、不替代医生，也不根据单一报告断言患病或治疗结论。
